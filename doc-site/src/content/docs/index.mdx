## Why Firefly MLS?

<CardGrid stagger>
	<Card title="RFC 9420 MLS Standard" icon="star">
		Built on modern Message Layer Security (MLS) with post-compromise security, forward secrecy, and efficient group key ratchets.
	</Card>
	<Card title="High-Performance Rust Core" icon="seti:rust">
		Underpinned by native Rust with N-API native bindings for Node.js and Bun, plus TypeScript SDKs.
	</Card>
	<Card title="Expressive Bot Framework" icon="laptop">
		Easily create command-driven chatbots (`bot.command(...)`) that automatically process and reply to 1-on-1 and group messages.
	</Card>
	<Card title="Embed Anywhere" icon="puzzle">
		Embed end-to-end encrypted messaging widgets directly into any web application, dashboard, or portal.
	</Card>
</CardGrid>
